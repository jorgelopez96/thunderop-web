# Idiomas y portada

La primera respuesta HTML se genera en el idioma solicitado por el navegador mediante Accept-Language. Una elección manual se guarda durante un año en la cookie thunderop_locale y tiene prioridad sobre las preferencias del navegador. Las variantes es-AR y en-US se asignan al idioma base; si no existe una traducción, se usa inglés. No se accede directamente a la configuración de Windows.

- src/lib/i18n/locales.ts: idiomas soportados y negociación con prioridades q.
- src/lib/i18n/messages.ts y page-messages.ts: diccionarios con el mismo esquema comprobado por TypeScript; el segundo agrupa Windows, comunidades, FAQ, soporte y pie de página.
- src/lib/i18n/context.svelte.ts: estado reactivo por instancia del layout; no compartir preferencias entre solicitudes.
- src/hooks.server.ts: resolución por solicitud y atributo lang del HTML.
- src/routes/+layout.server.ts: datos iniciales del idioma.
- src/lib/components/landing: portada y vista ilustrativa de la aplicación.
- src/lib/components/ui/LanguageSelector.svelte: selector nativo accesible, sin recargar la página.

Para agregar idiomas, ampliar la lista soportada, el registro de traducciones y las opciones del selector. Las etiquetas de navegación, los textos alternativos, los metadatos y el aviso de descarga también se traducen.

La vista de chat es una ilustración en HTML/CSS y no se conecta a conversaciones reales. El botón de descarga muestra un aviso de disponibilidad hasta contar con un instalador o una URL oficial.

## Verificación

- npm.cmd test: negociación de idioma, variantes regionales y elección recordada.
- npm.cmd run check: Svelte y TypeScript.
- npm.cmd run build: compilación.
- npm.cmd run test:e2e: pruebas con Edge instalado en Windows, sin descargar navegadores. Incluye selección y persistencia, HTML del servidor, navegación móvil, aviso de descarga y carga de la mascota.
- Las capturas y trazas van en .tmp, excluido de Git.
